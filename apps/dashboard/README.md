# Dashboard — מדריך קבצים

כל הקבצים כאן שייכים לממשק הניהול (React + Vite + TypeScript), שדרכו מנהלת המערכת מוסיפה ומעדכנת מועדונים, הטבות, מותגים וכו', בלי לגעת בקוד.
כדי להריץ בפועל: `npm install`, `npm run dev` (דורש שהשרת מ-`backend` רץ במקביל).

---

## שורש הפרויקט

**`index.html`** — נקודת הכניסה של האתר. מוגדר בכיוון RTL כי כל הממשק בעברית.

**`package.json`** — רשימת התלויות (React, React Router) וסקריפטים להרצה.

**`vite.config.ts`** — הגדרות כלי הבנייה (Vite).

**`tsconfig.json`** — הגדרות קומפילציית TypeScript.

---

## `src/` — קוד הממשק

**`main.tsx`** — נקודת הכניסה של React, טוענת את האפליקציה לתוך העמוד.

**`App.tsx`** — מגדיר את כל הניווט בין המסכים (איזו כתובת URL מציגה איזה מסך).

### `theme/`

**`tokens.css`** — כל צבעי וסגנונות הבסיס של הממשק (הצבע הסגול-לילך של BP, רדיוסים, גדלי טקסט), במקום אחד כדי שהעיצוב יישאר עקבי.

### `api/`

**`client.ts`** — כלי אחיד לתקשורת עם השרת (שליחת בקשות GET/POST/PATCH/DELETE וטיפול בתשובות).

### `components/` — רכיבים משותפים שחוזרים בכל הממשק

**`Badge.tsx`** — "תגית סטטוס" צבעונית (למשל "פעיל" בירוק, "ממתין לבדיקה" בצהוב) שמופיעה בעקביות בכל מסך.

**`layout/Layout.tsx`** — מבנה הקבוע של הממשק: התפריט הצידי (Sidebar) עם כל הקישורים למסכים, וההמסגרת שבתוכה כל מסך מוצג.

**`tables/DataTable.tsx`** — טבלה גנרית שמשמשת בכל מסכי הרשימה (הטבות, מותגים, מועדונים וכו'), כולל מצב טעינה ומצב "אין נתונים".

**`forms/FormPrimitives.tsx`** — רכיבי טופס בסיסיים (שדה טקסט, רשימה נפתחת, כפתור) בעיצוב אחיד לכל הטפסים.

**`forms/ScopeEditor.tsx`** — הרכיב שמאפשר להגדיר **למי בדיוק הטבה תקפה** (איזה מועדון + איזה מותג + איזה סניף), כולל אפשרות להוסיף כמה שילובים שונים לאותה הטבה. זהו הרכיב המורכב והחשוב ביותר בממשק, כי הוא מתרגם ויזואלית את "מנוע ההתאמה" של המערכת.

### `types/` — הגדרות טיפוסי הנתונים

קובץ אחד לכל ישות (`benefit.ts`, `brand.ts`, `campaign.ts`, `category.ts`, `coupon.ts`, `issuer.ts`, `program.ts`, `scrapedItem.ts`, `scraperSource.ts`, `store.ts`, `tag.ts`) — מגדיר איך המידע של אותה ישות בנוי, כדי שהקוד ידע למה לצפות מהשרת.

### `pages/` — כל מסכי הניהול

לכל ישות יש בדרך כלל שני קבצים: **מסך רשימה** (`*ListPage.tsx`) שמציג טבלה של כל הפריטים, ו**מסך טופס** (`*FormPage.tsx`) ליצירה/עריכה של פריט בודד.

**`Issuers/`** — ניהול מנפיקי הכרטיסים (MAX, Cal וכו').

**`Programs/`** — ניהול המועדונים והכרטיסים, כולל קביעת היררכיה (איזה כרטיס "תחת" איזה).

**`Categories/`** — ניהול קטגוריות ותת-קטגוריות.

**`Brands/`** — ניהול מותגים, כולל קיבוץ מותגים ומילות חיפוש נוספות.

**`Stores/`** — ניהול סניפים פיזיים.

**`Benefits/`** — ניהול ההטבות עצמן. זה המסך המרכזי, כולל את ה-ScopeEditor לקביעת מי זכאי לכל הטבה.

**`Coupons/`** — ניהול קודי קופון.

**`Campaigns/`** — ניהול קמפיינים (איגוד כמה הטבות יחד).

**`Tags/`** — ניהול תגיות חופשיות.

**`ScraperSources/`** — ניהול מקורות הסריקה האוטומטית: הוספת אתר חדש לסריקה, ובעיקר **אישור תנאי השימוש** של האתר (שלב חובה לפני שהמערכת מותרת לסרוק אותו) והפעלה/כיבוי של הסריקה.

**`ScrapedItems/`** — "תור הבדיקה": רשימת כל ההטבות שהסורק מצא ולא היה בטוח מספיק לגביהן כדי לפרסם אוטומטית, כולל הסבר למה כל פריט הגיע לבדיקה, ואפשרות לאשר או לדחות.
